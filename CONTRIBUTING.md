# Contributing

Use Discussions for hypotheses and comparison across models. Use Issues for a reproducible finding or a specific defect. Include model and firmware, operating system, software revision, provider version and adapter type where relevant. Identify whether evidence came from source review, a mock, a historical observation or a physical measurement.

Use synthetic fixtures for pull requests. Explain the expected behavior, show the test command and report the results. Leave private serials, license keys, calibration data, firmware, disk contents and unrestricted logs out of posts and attachments. Publish only material you have permission to share. Cite a source URL, revision and author when reporting third-party findings.

See the [research questions](docs/RESEARCH_QUESTIONS.md) and [security reporting guidance](SECURITY.md).
