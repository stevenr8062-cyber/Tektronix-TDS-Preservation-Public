# Source provenance and attribution

The synthetic parser and tests are project-authored. The parser is carried forward from the project's internal offline prototype. No upstream source, manuals, traces or binaries are bundled.

- [Jared Cabot, TDS Toolkit, 1.4.0 source](https://github.com/JaredCabot/tds-toolkit/tree/e2dc2f3f4ce31d39d78748edcf26106c8ebad810). Reference for host compatibility and source behavior.
- [Ragnar’s tektools](https://github.com/ragges/tektools/tree/e27e36259f2089f05a18a798260b21e44bf87303) and [Albert’s fork](https://github.com/tantratron/tektools/tree/e27e36259f2089f05a18a798260b21e44bf87303). References for community tools and logical calibration interpretation.
- [flyte’s floppy-dumper discussion](https://www.eevblog.com/forum/testgear/tektronix-tds500600700-nvram-floppy-dump-tool/). Community preservation research.
- [TekScopes discussion](https://groups.io/g/TekScopes/topic/122346162) and [EEVblog discussion](https://www.eevblog.com/forum/testgear/tektronix-tds784d-backing-up-hdd-nvram-and-calibration-data-via-keysight-usb/). Thanks to Albert, Jared Cabot (TERRA Operative), and Insatman for sharing their experience. A report about another unit or software stack has limited applicability.
- [PyVISA documentation](https://pyvisa.readthedocs.io/) and [Keysight software revision matrix](https://helpfiles.keysight.com/IO_Libraries_Suite/English/IOLS_Windows/IOLS/Content/Introductory_Topics/Reference_Topics/Revision_Matrix.htm). References for the host investigation. The demonstration imports neither VISA package nor driver.
